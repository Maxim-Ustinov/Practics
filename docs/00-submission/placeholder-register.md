# Реестр placeholders и данных владельца

Placeholders нельзя заменять предположениями. Заполнение выполняет владелец проекта после проверки документа-основания.

| Группа | Поля | Где | Подтверждение |
|---|---|---|---|
| Контакты | имя, Telegram, e-mail | `docs/pitch/`, landing | согласованный контакт владельца |
| Команда | ФИО, роль, опыт, ссылки | `docs/pitch/pitch-deck.md`, HTML | подтверждение каждого участника |
| Юрстатус | ИП/ООО, ФИО, ИНН, ОГРНИП/ОГРН, адрес | `landing/privacy.html`, `terms.html`, занятия №15/17/19 | выписка ЕГРИП/ЕГРЮЛ и консультация юриста |
| Права | правообладатель кода, дизайна, домена, логотипа | занятие №15, финальный отчёт | договоры, акты, аккаунты |
| Платежи | ShopId, секреты, webhook, возвраты | billing-документы | настройки кабинета и тестовый платёж |
| Метрики | пользователи, оплаты, CAC, retention, delivery rate | pitch, MVP-отчёт | логи/аналитика с датой и методикой |
| Подписанные материалы | листы задания, отзыв, подписи | `01-topic-and-assignment/`, `06-final-report/review/` | скан/официальный файл |
