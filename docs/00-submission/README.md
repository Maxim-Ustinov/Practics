## Канонические статусы

- **Факт репозитория** — подтверждается конкретным кодом или документом в текущем срезе.
- **Технически предусмотрено** — компонент или заготовка присутствует, но пользовательский результат не доказан.
- **Локально проверено** — проверено в локальном окружении; это не production/E2E.
- **E2E-проверено** — есть воспроизводимая запись полного сценария с окружением и результатом.
- **Гипотеза / учебный сценарий / план** — не выдавать за достигнутый результат.
- **Требует подтверждения** — сведения владельца, официальная регистрация, реквизиты, договоры, платежи и внешние данные.
