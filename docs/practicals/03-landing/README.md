# Практическое занятие №3. Хостинг продающего сайта

## Титул и содержание

**TenderScope — статический лендинг с CTA раннего доступа.**  
Содержание: требования → структура → запуск → CTA → проверка → источники и приложения.

## Основная часть

Основной артефакт — [`landing/index.html`](../../../landing/index.html). Сайт содержит hero, проблему, сценарий работы, возможности, тарифы, аудиторию, FAQ и CTA. Реализация — HTML/CSS/vanilla JS без backend.

CTA работает через `mailto:`: форма валидирует поля и открывает почтовый клиент пользователя. Данные не сохраняются на сервере и доставка письма не гарантируется. `privacy.html` и `terms.html` — черновые шаблоны с placeholders, не готовые юридические документы.

## Результат и ограничения

Структура и локальный запуск подготовлены. Публичный production-деплой в рамках этого комплекта не подтверждён. Pro 999 ₽/мес — целевая модель; онлайн-оплата не подтверждена. Push не рекламируется как работающий: интеграционные компоненты присутствуют в коде, но фактическая доставка на устройстве не подтверждена.

## Выводы

Лендинг выполняет учебную задачу по структуре и CTA, но перед публикацией требуются проверка домена/контактов, юрист, подтверждение реквизитов, тест формы и решение о backend для заявок.
