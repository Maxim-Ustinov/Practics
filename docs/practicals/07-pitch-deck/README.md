# Практическое занятие №7. Поиск инвесторов и привлечение инвестиций

## Титул и содержание

**TenderScope — pitch deck для pre-seed обсуждения.**  
Содержание: инвестор → проблема → решение → рынок-гипотеза → конкуренты → модель → текущий статус → команда → Ask → speaker notes.

## Основная часть

Основные артефакты находятся в [`docs/pitch/`](../../pitch/): `pitch-deck.html`, `pitch-deck.md`, `speaker-notes.md`, `elevator-pitch.md`, `README.md`. Дек содержит 10 слайдов, что укладывается в требование методички 7–10 слайдов.

Публичные пользователи и выручка не заявляются. Рынок, CAC/LTV, конверсия, сроки roadmap и Ask — гипотезы/план. Имена команды и контакты оставлены placeholders до получения данных владельца. Цена Pro 999 ₽/мес — целевая; боевой платёж не подтверждён.

## Ключевой дисклеймер

Интеграционные компоненты push присутствуют в коде, но фактическая доставка на устройстве не подтверждена. ЮKassa scaffold присутствует, но кабинет, секреты, webhook и боевой платёж не подтверждены.

## Выводы

Дек пригоден для учебной защиты как честное pre-seed позиционирование продукта и плана проверки. До публичной отправки нужно заполнить только подтверждённые контакты/биографии, проверить рыночные источники и пересчитать бюджет.
