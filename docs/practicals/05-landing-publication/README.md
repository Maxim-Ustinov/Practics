# Практическое занятие №5. Публикация продающего сайта

## Титул и содержание

**TenderScope — публикация и проверка статического лендинга.**  
Содержание: повторяемые требования методички → выбранный способ размещения → чек-лист публикации → выводы → источники и приложения.

## Основная часть

Задание №5 использует тот же артефакт, что и занятие №3, поэтому HTML/CSS/JS не дублируются. Инструкции запуска и деплоя находятся в [`landing/README.md`](../../../landing/README.md) и [`landing/DEPLOY.md`](../../../landing/DEPLOY.md).

Выбран технический статический вариант: локальный `python -m http.server` для проверки и отдельный VPS-деплой по инструкции. Деплой не считается выполненным без записи URL, даты, проверки HTTPS, ссылок и формы.

## Статус публикации

| Проверка | Статус |
|---|---|
| Локальная структура и адаптивность | проверить перед сдачей |
| CTA/mailto | технически предусмотрено; проверить в браузере |
| Production URL | требует подтверждения владельца |
| Privacy/terms | учебные черновики, нужна юридическая проверка |
| Онлайн-оплата | отсутствует/не подтверждена |

## Выводы

Артефакт пригоден для учебной демонстрации лендинга. Нельзя выдавать локальный сервер или инструкцию деплоя за факт опубликованного сайта. Форма не является backend-сбором заявок.
