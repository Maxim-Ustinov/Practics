# Практическое занятие №17. Регистрация компании. Юридические аспекты

**Проект:** TenderScope — мобильное приложение для поиска и анализа госзакупок.  
**Дата подготовки:** 03.11.2026.  
**Статус материала:** учебный комплект, не заявление и не юридическое/налоговое заключение.

## Важное различие статусов

В `PROJECT_CONTEXT.md` указано: **«Регистрация ИП подана/получена; далее подключить ЮKassa как ИП»**. В документе нет даты, номера ОГРНИП, ИНН или подтверждения конкретного результата. Поэтому точный текущий статус следует подтвердить по ЕГРИП/документам основателя.

Модель ООО в этой работе — **отдельный учебный сценарий** для сравнения организационно-правовой формы. ООО не регистрируется, документы не направляются в ФНС, банковский счёт не открывается.

## Ограничения и порядок проверки

1. Все значения в квадратных скобках — placeholders, их нельзя заменять догадками.
2. Перед реальными действиями проверить ЕГРЮЛ/ЕГРИП, актуальную форму Р11001, региональные ставки, ОКВЭД и требования банка.
3. Ставки и расчёты ниже — учебная модель. Реальный выбор должен подтвердить бухгалтер/налоговый консультант, а устав и корпоративную структуру — юрист.
4. Источники ФНС приведены с датой доступа 03.11.2026. При подаче документов нужно открыть страницы заново: законодательство и формы меняются.
