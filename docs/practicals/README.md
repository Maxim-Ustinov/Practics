## Общий шаблон каждого занятия

README → титул → содержание → основной материал → выводы → источники с датами доступа → приложения → реестр фактов/допущений/placeholders. Если существующий материал уже соответствует, он не копируется в новую папку: README даёт навигацию на канонический источник.
