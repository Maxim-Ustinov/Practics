# Тема и задание

## Титульная формулировка

**TenderScope — мобильный AI-сервис мониторинга и анализа государственных закупок для малого бизнеса.**

## Краткое содержание

Продукт предназначен для ИП и малых ООО без тендерного отдела. Пользователь описывает задачу естественным языком; система формирует поисковый профиль, показывает ленту закупок из `zakupki.gov.ru`, помогает оценить документы и заказчика. MVP ограничен 44-ФЗ и 223-ФЗ. Подача заявок, коммерческие площадки, бухгалтерия и юридическая гарантия результата не входят в границы.

## Что приложить владельцу

- [ ] согласованный лист задания;
- [ ] подписи преподавателя и студента;
- [ ] скан/фото подписанных листов;
- [ ] подтверждение темы от кафедры;
- [ ] фактический состав команды, если он должен быть указан.
