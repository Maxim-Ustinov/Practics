# Экспорт и печать отчёта

- [ ] Принять требования кафедры к DOCX, PDF, шрифту, полям и нумерации.
- [ ] Собрать Markdown в DOCX только после проверки текста и ссылок.
- [ ] Открыть DOCX и PDF на другой машине.
- [ ] Проверить оглавление, переносы таблиц, изображения, колонтитулы и нумерацию.
- [ ] Для HTML-презентаций использовать браузерный экспорт: Chrome/Edge → `Ctrl+P` → «Сохранить как PDF» → фон → нужная ориентация.
- [ ] Сверить число страниц/слайдов вручную.
- [ ] Не включать реальные секреты, персональные данные и неподтверждённые реквизиты.
