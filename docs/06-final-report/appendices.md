# Приложения к итоговому отчёту

1. Схема архитектуры и поток данных.
2. Скриншоты реального приложения с датой и пометкой окружения.
3. Протокол parser/business-тестов.
4. Ручной E2E-протокол: регистрация → профиль → лента → чат → сохранение.
5. E2E-протокол push, если будет выполнен.
6. Протокол тестового платежа, если будет выполнен.
7. Таблица гипотез и результатов интервью.
8. Реестр источников и дат доступа.
9. Реестр placeholders и документы владельца.
10. Подписанные листы задания, отзыв и журнал правок.

Незаполненное приложение помечается «не приложено / требует подтверждения», а не заменяется модельным результатом.
