# Обзор рынка и существующих решений

## Титул и содержание

**Тема:** рынок инструментов мониторинга государственных закупок и ниша TenderScope.  
**Содержание:** методология → источники → сегменты → карта конкурентов → проверяемые выводы → ограничения.

## Основной материал

В текущем комплекте нельзя выдавать модельные TAM/SAM/SOM, готовность платить и качественную карту конкурентов за подтверждённые результаты. Для завершения раздела нужно собрать официальные данные ЕИС/Минфина/ФНС, актуальные тарифы конкурентов с датой доступа и обезличенные интервью. Existing pitch и занятия №9/13 содержат рабочие гипотезы, а не доказательство рынка.

## План исследования

1. Зафиксировать период и критерии включения поставщиков.
2. Для каждой цифры записать формулу, первоисточник, дату доступа и ограничение.
3. Разделить государственную статистику, коммерческие обзоры, интервью и авторские оценки.
4. Не называть рынок подписок объёмом госзакупок.
5. Конкурентов сравнивать по проверяемым функциям и тарифам; не утверждать отсутствие конкурентов.

## Вывод на текущем срезе

Ниша mobile-first + естественный язык + объяснение документов остаётся гипотезой позиционирования. Публичный спрос, доли рынка, цены конкурентов и готовность платить требуют отдельного исследования.
