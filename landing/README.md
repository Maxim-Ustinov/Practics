# TenderScope — лендинг

Одностраничный статический лендинг продукта TenderScope: «Умный поиск закупок для бизнеса».
Без сборщика, фреймворков и бэкенда: HTML + CSS + небольшой vanilla JS.

- Продукт: мобильное приложение для ИП и малых ООО, которые участвуют в госзакупках по 44-ФЗ и 223-ФЗ.
- Аудитория: небольшие компании без тендерного отдела.
- Тарифы: Free (0 ₽) и целевая модель Pro (999 ₽/мес); онлайн-оплата ещё не подтверждена.
- Бренд: фон `#1F1F1F`, синий `#4F7CFF`, золотой `#FFB547`, текст `#F5F5F7`, шрифт Manrope.

## Локальный запуск

Открыть `index.html` двойным щелчком можно, но для корректной проверки относительных путей и `fetch`-поведения лучше поднять локальный сервер.

Из корня репозитория:

```powershell
python -m http.server 8080 --directory landing
```

Или из папки `landing`:

```powershell
cd landing
python -m http.server 8080
```

Затем открыть <http://localhost:8080/>.

Альтернатива без Python:

```powershell
npx serve landing
```

## Как работает форма заявки

Форма полностью работает без бэкенда:

1. Пользователь заполняет имя, email/Telegram и ставит согласие.
2. `script.js` валидирует поля и показывает ошибки рядом с полями.
3. При успешной валидации собирается письмо на `hello@tenderscope.ru`:
   - тема: `Заявка с сайта TenderScope — <имя>`;
   - тело: имя, контакт, отметка о согласии, дата.
4. Открывается почтовый клиент пользователя через `mailto:`.
5. На экране появляется сообщение об успехе и кнопка «Открыть письмо ещё раз» на случай, если клиент не открылся.

Важно:

- Данные нигде не сохраняются: ни в localStorage, ни на сервере. Это честный `mailto`-сценарий, а не имитация отправки.
- Доставка письма зависит от почтового клиента пользователя. Если клиент не настроен, форма предлагает написать на почту или в Telegram.
- Consent checkbox обязателен; без него форма не отправится.
- Ссылка на политику в форме ведёт на `privacy.html` и открывается в новой вкладке, чтобы не потерять заполненные поля.

Контакты, используемые в CTA:

- почта: `hello@tenderscope.ru`;
- Telegram: <https://t.me/tenderscope>.

Если контакты изменятся, их нужно заменить в `index.html`, `privacy.html`, `terms.html`, `script.js` (mailto) и `README.md`.

### Юридическая проверка

`privacy.html` и `terms.html` — **шаблоны, а не готовые юридические документы**. Перед публикацией их должен проверить юрист, специализирующийся на 152-ФЗ, защите прав потребителей и рекламе. Особенно важно проверить:

- реквизиты оператора и адрес для обращений;
- основания и сроки обработки персональных данных;
- формулировки согласия в форме заявки;
- упоминание Google Fonts и хостинга как получателей технических данных;
- дисклеймеры об AI-оценках и данных ЕИС;
- порядок изменения тарифов и условий.

## Шрифт и внешние ресурсы

Manrope подключён через Google Fonts с `display=swap` и fallback-стеком:

```css
font-family: "Manrope", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
```

Если нужен полностью автономный сайт (без запросов к Google), скачайте woff2-файлы Manrope, положите их в `assets/fonts/` и замените `<link>` на `@font-face` в `styles.css`. Это также стоит сделать, если политика требует минимизировать передачу IP третьим лицам.

Других внешних библиотек нет. Все иконки — inline SVG, иллюстрации — локальные SVG.

## Визуальные мокапы

Скриншотов приложения в репозитории нет, поэтому экраны собраны на CSS/SVG:

- чат в hero (запрос → фильтры → карточка закупки);
- карточка тендера с AI-оценкой в блоке «Возможности»;
- аналитика заказчика с метриками и AI-выводом.

Все мокапы подписаны «Пример интерфейса · демо-данные» / «Пример карточки · демо-данные». Это иллюстрации, а не реальные данные пользователей или заказчиков. На сайте нет фейковых отзывов, логотипов клиентов, наград и выдуманных метрик продукта.

## SEO и доступность

- `title`, `description`, canonical, Open Graph, Twitter Card, theme-color.
- JSON-LD `Organization` + `WebSite` без выдуманных рейтингов и отзывов.
- Семантические `header`, `main`, `section`, `nav`, `footer`, `details/summary`, таблица с `caption`.
- Один `h1`, иерархия заголовков, alt у изображений (декоративные — с пустым alt).
- Skip-link, видимые focus-состояния, `aria-expanded` у мобильного меню, `aria-live` у сообщения об успехе.
- `prefers-reduced-motion` отключает анимации и плавный скролл.
- Контраст текста проверен для тёмной темы; основной текст не светлее `#A6A6AE` на `#1F1F1F`.

## Ограничения

- Нет бэкенда, аналитики и cookie-баннера, потому что сайт не собирает аналитику.
- Нет подтверждённой онлайн-оплаты: Pro указан как целевой тариф, кабинет/секреты/webhook и боевой платёж не подтверждены.
- Push: интеграционные компоненты есть в коде, но фактическая доставка на устройстве не подтверждена.
- Нет автоматической отправки письма: только `mailto` через почтовый клиент.
- Нет реальных скриншотов приложения — только стилизованные демо-мокапы.
- Юридические тексты требуют проверки (см. выше).
